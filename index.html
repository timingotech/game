FRIDAY TEAM GAME · HOST CONTROL ROOM

DEFEND THE UNDEFENDABLE.

Ridiculous arguments. Random matchups. Very serious nonsense. 🎭

👥 10–20 players⏱️ 30–45 min💻 Online friendly

01 / Set up your players

Paste everyone’s name, one per line (or separate names with commas). Then randomly pair them.
For live voting: make one Multiple Choice slide per matchup in Mentimeter. Every slide needs just two choices: the two debaters. Share its voting link in the meeting chat.

02 / The rules

  1. Randomly select a FOR and AGAINST speaker.
  2. Announce the absurd statement. No switching sides!
  3. Give each 40 seconds for an opening argument.
  4. Give each 20 seconds for a rebuttal.
  5. Audience gets 20 seconds to vote for the best argument.
  6. Record the winner here; +1 point. No votes from the two debaters.
If there is an odd number of people, one sits out during the first matching cycle and can vote. The next cycle prioritizes that person.
